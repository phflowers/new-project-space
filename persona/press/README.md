# Press releases

Drafted for distribution via EIN Presswire and similar wires.

## House rules

Each release is drafted against three standards, in this order:

1. **Persona voice guide** (`../voice/style_guide.md`) — every factual
   claim maps to a source the reader could verify; opinion is
   labeled and attributed.
2. **EIN Presswire editorial guidelines** — no defamation, no
   unsupported allegations against identifiable parties, no
   profanity, opinion is labeled and attributed to Paul, all cited
   court cases and enforcement actions are matters of public
   record.
3. **Fiduciary posture** — nothing in a release may put the
   Validation Institute Fiduciary Advisor certification at risk.

## Placeholders in every draft

- `[DATE]` — set to the day of distribution.
- Media contact block — email, phone, and any campaign-specific
  URL (book-a-call, download link) to be filled before submission.
