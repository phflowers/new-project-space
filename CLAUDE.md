# Project memory

This repo carries a writing persona, not just code.

When helping me write, read `persona/README.md` first, then the four
dossiers in `persona/identities/`, then `persona/voice/style_guide.md`.

The cover image is `persona/images/source/business_cards.jpg` (four
former roles — USI, Cigna, Hines, Fountain Health — on one desk). The
per-role crops live in `persona/images/cropped/` and are produced by
`scripts/split_business_cards.py`.

The voice is first-person former-insider, investigative, sourced. The
hard lines (no PHI, no named clients, no privileged material) are in
the style guide. Do not draft anything that crosses them, and flag if
a piece I'm working on starts to drift toward one.
